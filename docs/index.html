Install Cursor Browser

Give Cursor agents your real Chrome, Edge, Brave, or Firefox — signed-in tabs, in a visible Cursor group. Not the built-in Browser Tab.

1. Add the browser extension

Store listings go live after review. Until then, use the packaged zip (one Load unpacked).

Add to Chrome / Edge / Brave Add to Firefox
  1. Download the zip and unzip it.
  2. Chrome / Edge / Brave: chrome://extensions → Developer mode → Load unpacked → the unzipped folder.
  3. Firefox: about:debugging#/runtime/this-firefox → Load Temporary Add-on → manifest.json.
  4. Pin Cursor and wait until the popup says Connected.

2. Add the Cursor plugin

From this repo (easiest if you already have it open):

pnpm install && pnpm sync && pnpm install-hosts

Or drop the plugin zip into ~/.cursor/plugins/local/cursor-browser, then reload Cursor.
