Privacy policy

Cursor Browser lets the Cursor desktop app drive tabs in your installed browser. It is a local bridge. It is not a cloud browser.

What the extension can access

  • Tabs and tab groups it creates for Cursor.
  • Page content, screenshots, console and network data on those tabs, after you allow a site.
  • A pairing token from the Cursor plugin running on your machine (127.0.0.1 only).

What we do not do

  • We do not operate a backend that receives your browsing data.
  • We do not sell data, inject ads, or run analytics SDKs.
  • Page content only leaves your machine if you send it into a Cursor chat (that follows Cursor’s own data controls).

Permissions

Host access and the page debugger exist so the agent can click, type, and screenshot like a user. Native messaging talks to the local Cursor plugin. You can disconnect or uninstall at any time.
